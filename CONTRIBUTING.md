# Contributing to Ghazals-hn-es

Thank you for your interest in contributing to this collection of Hindi ghazals and their Spanish translations! This guide will help you add new content or improve existing translations.

## 📝 How to Contribute

### Adding a New Ghazal

1. **Choose the appropriate theme directory** under `/ghazals/`
   - ishq (Love)
   - judai (Separation)
   - zindagi (Life)
   - dard (Pain/Sorrow)
   - khushi (Happiness)
   - falsafa (Philosophy)
   - hasrat (Desire/Longing)
   - yaadein (Memories)

2. **Create a new markdown file** following the naming convention:
   - Format: `poet-name-first-words.md`
   - Example: `ghalib-hazaaron-khwaishein.md`

3. **Use the following template:**

```markdown
# [Title or First Line in Hindi]

**Poet:** [Poet Name in English] ([Poet Name in Hindi])  
**Theme:** [Theme Name]  
**Era:** [Time period, e.g., 19th Century, Contemporary]

---

## Original (Hindi/Urdu - Devanagari)

[Full ghazal in Devanagari script]

---

## Transliteration (Romanized)

[Romanized version for pronunciation]

---

## Spanish Translation (Traducción Española)

[Spanish translation maintaining poetic essence]

---

## Context / Notes

[Any relevant context about the ghazal, historical background, or cultural significance]

---

## About the Poet

[Brief information about the poet]
```

4. **Update INDEX.md**
   - Add the new ghazal to the appropriate sections
   - Include poet name, title, theme, and file path

### Translation Guidelines

#### For Hindi/Urdu Text:
- Use proper Devanagari script
- Maintain original line breaks and structure
- Preserve traditional spelling and diacritics

#### For Romanization:
- Use standard romanization conventions
- Be consistent with transliteration choices
- Make it readable for non-Hindi speakers

#### For Spanish Translation:
- Prioritize conveying the emotional essence over literal translation
- Maintain poetic rhythm where possible
- Use appropriate Spanish poetic vocabulary
- Add translator notes if cultural concepts are difficult to translate

### Quality Standards

1. **Accuracy:** Ensure the Hindi text is accurate and properly attributed
2. **Attribution:** Always credit the original poet
3. **Cultural Sensitivity:** Respect the cultural and historical context
4. **Quality Translations:** Spanish translations should be reviewed by native speakers
5. **Formatting:** Follow the markdown template consistently

## 🔍 Review Process

1. Submit a pull request with your addition
2. Ensure the file follows the template
3. Verify INDEX.md is updated
4. Maintainers will review for accuracy and quality
5. Address any feedback before merging

## ⚖️ Copyright and Attribution

- Only include works that are in the public domain or have proper permissions
- Always attribute works to their original authors
- Translations should credit the translator
- For contemporary poets, ensure copyright compliance

## 💡 Suggestions for New Themes

If you believe a new theme category should be added, please:
1. Open an issue explaining the theme
2. Provide examples of ghazals that would fit
3. Suggest a Hindi and Spanish name for the theme

## 🌟 Other Ways to Contribute

- Improve existing translations
- Add missing transliterations
- Provide cultural context and notes
- Fix typos or formatting issues
- Suggest improvements to organization

## 📧 Questions?

If you have questions about contributing, please open an issue for discussion.

Thank you for helping preserve and share these beautiful works of poetry! 🙏
