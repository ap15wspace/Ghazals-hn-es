# Ghazals-hn-es 🌹
## Hindi Ghazals with Spanish Translations

A curated collection of popular Hindi ghazals, shayari, and poetic writings with their Spanish translations, organized by themes.

## 📚 Collection Overview

This repository contains:
- Classic and contemporary Hindi ghazals
- Popular shayari and couplets
- Poetic writings by renowned Urdu/Hindi poets
- Spanish translations of each piece

## 🗂️ Organization by Themes

The collection is organized into the following themes:

### 1. **Ishq (Love - Amor)**
Ghazals and shayari about love, romance, and passion

### 2. **Judai (Separation - Separación)**
Poetry about separation, longing, and distance

### 3. **Zindagi (Life - Vida)**
Reflections on life, existence, and philosophy

### 4. **Dard (Pain/Sorrow - Dolor)**
Expressions of pain, grief, and melancholy

### 5. **Khushi (Happiness - Felicidad)**
Celebrations of joy, happiness, and bliss

### 6. **Falsafa (Philosophy - Filosofía)**
Philosophical musings and wisdom

### 7. **Hasrat (Desire/Longing - Anhelo)**
Poetry about unfulfilled desires and yearning

### 8. **Yaadein (Memories - Recuerdos)**
Nostalgic reflections and memories

## 📖 How to Navigate

Browse the `/ghazals` directory to find poems organized by theme. Each file contains:
- Original Hindi/Urdu text (in Devanagari script)
- Romanized transliteration
- Spanish translation
- Poet name and additional context

See [INDEX.md](INDEX.md) for a complete list of all ghazals and poets.
